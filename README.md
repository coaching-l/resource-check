# 人生のリソースの棚卸し（COACHING-L）

時間・エネルギー・感情の現在地を知る5分のセルフチェックです。
公式LINE登録の特典として、自分の時間・エネルギー・感情の使い方を棚卸しし、「どこでエネルギーが漏れているか」に気づいて、小さな一歩を決めるためのものです。
診断や心理検査ではなく、自分をふりかえるためのセルフチェックです。

提供：COACHING-L（コーチ：刈谷洋介）

- ブラウザだけで動く静的サイトです（インストール・登録は不要。HTML・CSS・JavaScript だけで、ビルドも不要）
- 回答と記入内容は、この端末の中（`localStorage`）だけに保存され、外部には送信されません
- スマホ優先のレイアウトで、PC でも使えます。ライト／ダークは、端末の表示設定に合わせて自動で切り替わります
- 仕様は [SPEC.md](SPEC.md) にあります

公開 URL：https://tools.coaching-l.net/resource-check/

## 画面の流れ

1. **スタート**：タイトル・副題・所要時間（約5分＋ふりかえり5分）・説明文と、「これは診断ではなく…」の一文。前回の記録があれば「前回の結果を見る」と、その日付も出します。
2. **質問**（5領域×4問＝20問）：1画面に1領域（4問）。上部に進み具合（1 / 5）を出します。
   各問を「1 ほとんどない／2 あまりない／3 ときどきある／4 よくある／5 いつも」から選びます。4問すべてに答えるまで「次へ」は押せません。「戻る」で前の画面に戻れます（1画面目の「戻る」はスタートへ。回答は残り、「続きからはじめる」で戻れます）。
3. **結果**「あなたのエネルギーの収支」：5領域の収支を、0 を真ん中にした横向きの棒（左右に伸びる収支バー）で表示します。
   - 漏れが大きい順（収支の小さい順）に上から並べます
   - 充電できている＝紺、漏れている＝落ち着いた赤、とんとん＝灰色。どの棒にも領域名・ラベル・数値（例：−1.3）を添えます（色だけに頼らない）
   - 前回の結果があれば、前回の収支を細い金色の棒で重ね、「前回 +0.3（とんとん）」のように文字でも出します
   - 「いちばん整っている領域」と「いちばん漏れている領域」を文で示し、注意書きを添えます
   - 「感情の消耗」か「回復の習慣」の得点が 1.5 以下のときだけ、専門家への相談の一文を添えます
4. **ふりかえり**：いちばん漏れている領域の問いを、1画面に1問ずつ3問。最初の画面に「紙とペン」の案内を出します。記入欄は任意で、空欄でも進めます。
   「回復の習慣」の問い2は、4つの選択肢から1つをタップでも選べます（もう一度押すと外れます。任意）。
5. **小さな一歩**：「この1週間で試してみる、小さな一歩を1つ決めるとしたら？」に記入して「まとめを見る」。
   **まとめ**には、収支バー・ふりかえりの記入・小さな一歩をまとめて表示し、「テキストでコピー」と「印刷する（PDFで保存）」のボタン、「1か月後に、もう一度…」の案内を出します。
   コピーと印刷の前に、**お名前（任意）**を入れられます。入れると印刷とコピーの文章に「お名前：…」が入り、印刷のページ名（PDFのファイル名になることが多い）も「人生のリソースの棚卸し_お名前_20261020」になります。コーチングセッションで使う方が、コーチに共有しやすくするためのものです。お名前は次回も入った状態で出ます。
6. **結びの案内**（まとめの下に控えめに）：統合型パーソナルコーチングの概要・個別無料説明会へのリンク（押したときだけ、別のタブで開きます）。
7. **このセルフチェックの背景**：スタートとまとめの下の折りたたみ。考え方と参考文献（SPEC.md の表記のまま）を載せています。

### 記録と「前回」

- 20問に答えて結果を出した時点で、その回の結果を日付つきで保存します。ふりかえりや小さな一歩を途中でやめても、収支は次回の比較に使えます。
  ふりかえりと小さな一歩の記入は、同じ記録にあとから足していきます（入力が止まって少したつと自動で保存。画面を閉じるときにも保存）。
- 「前回」は、その回の1つ前に保存した結果です。同じ日に2回やったときは、1回目が「前回」になります。
- 途中で画面を閉じても、12時間以内に開けば続きの画面から表示します。それより時間がたっていたらスタートから表示します（結果を出したあとの記録は残っています）。
- 「記録を消す」（スタートとまとめの下）で、この端末に保存した回答・記入内容・過去の結果・お名前をすべて消せます（確認あり）。

## 採点のしかた（SPEC.md の「2. 採点」）

採点は [`scoring.js`](scoring.js) にまとめてあります。

| 手順 | 内容 |
| --- | --- |
| 各問の点 | 答え（1〜5）。（逆）の問いは 1→5、2→4、3→3、4→2、5→1 に逆転 |
| 領域の得点 | 4問の平均（1.0〜5.0）。小数第1位まで四捨五入（例：3.25 → 3.3） |
| 収支 | 得点 − 3.0（−2.0〜＋2.0） |
| 区分 | ＋0.5 以上「充電できている」／−0.5 以下「漏れている」／その間「とんとん」 |
| いちばん漏れている領域 | 収支がいちばん小さい領域。同点は領域1→5の順で先のもの。全領域が「とんとん」以上でも、いちばん収支の小さい領域の問いを出します |
| いちばん整っている領域 | 収支がいちばん大きい領域。同点は領域1→5の順で先のもの |
| 専門家への相談の一文 | 「感情の消耗」か「回復の習慣」の得点が 1.5 以下のとき |

逆転する問いは7問です：時間の主導権 3・4／集中の質 3／感情の消耗 1・2・4／優先順位 3。
画面には（逆）の印は出しません。

4問の平均は 0.25 刻みなので、四捨五入しても区分は変わりません（例：収支 +0.25 → 表示は +0.3 で「とんとん」、+0.5 → 「充電できている」）。

## 文言の直し方（content.js）

質問・ふりかえりの問い・画面の文言は、すべて [`content.js`](content.js) にまとめています。テキストエディタで開き、`" "` の中の文字だけを書き換えてください。

- `"` と、行の終わりの `,` は消さないでください
- `{name}` や `{date}` のような `{ }` の部分は、アプリが名前や日付に置き換えます。そのまま残してください
- `id: "time"` などの `id` は、保存した記録と結びつけるための名前です。変えないでください
- 質問の並び順は変えないでください（前回までの回答とずれるため）。文だけを直すのは問題ありません
- `reverse: true` は、逆転して採点する質問です
- 参考文献の `*…*` で囲んだ部分は、画面では斜体になります
- 直したら、`index.html` の `content.js?v=1` の数字を1つ上げてください（下の「公開」を参照）
- ページのタイトルと副題は、LINE でリンクを貼ったときの表示のため `index.html` の `<title>` と `<meta name="description">` にも書いてあります。変えたときは、ここもそろえてください

文言を SPEC.md から変えた場合は、テスト（`tests/content.test.js`）が「SPEC.md と違う」と知らせます。意図した変更なら、SPEC.md も同じように直してください。

## プライバシー

- 回答・記入内容・過去の結果・お名前（任意）は、お使いのブラウザの `localStorage`（キー：`coachingl-resource-check-v1`）にだけ保存されます
- 外部への通信は一切しません。解析ツール、Cookie、外部フォント、CDN も使っていません。グラフも外部ライブラリを使わず HTML と CSS で描いています
  - `index.html` の Content-Security-Policy で、外部への接続そのものも禁止しています
  - 外への移動は、結びの案内の2つのリンクを押したときだけです
- 「テキストでコピー」や「印刷」で取り出した内容は、本人が選んだ相手にだけ渡ります
- 記録は端末・ブラウザごとに別々です。別の端末と同期されることはありません
- iPhone・Mac の Safari は、しばらく開かなかったサイトの保存データを自動で消すことがあります。そのときは前回の結果が表示されません
- **記録の保存場所は、開き方ごとに別々です。** LINE の中で開いたページは、LINE の中に保存されます。Safari や Chrome で開き直すと、前回の結果は表示されません
  - 1か月後の比較のためには、いつも同じ開き方をしてもらうのがおすすめです。LINE で案内する URL は、末尾に `?openExternalBrowser=1` を付けると、LINE の中ではなく端末のブラウザ（Safari・Chrome）で開きます
  - 例：`https://tools.coaching-l.net/resource-check/?openExternalBrowser=1`
  - LINE の中で開いたときは、「印刷する」が働かないことがあります（「テキストでコピー」は使えます）
- GitHub Pages では、`tools.coaching-l.net` の下のツール（ポモドーロタイマーなど）どうしで保存場所（オリジン）が共通になります。キーの名前を分けているので、互いの記録を上書きすることはありません。「記録を消す」も、このアプリのキーだけを消します

## テスト

採点と文言を、ブラウザなしで確かめるテストがあります。Node.js（18 以上）があれば、インストールするものはありません。

```sh
node --test
```

| ファイル | 確かめること |
| --- | --- |
| `tests/scoring.test.js` | 逆転項目・平均と四捨五入・収支・区分の境目（±0.5）・全625通りの答え・並び順と同点・専門家の一文の条件 |
| `tests/content.test.js` | 20問と（逆）の印・ふりかえりの問い・参考文献・画面の文言が SPEC.md と一字一句同じか。使わない言葉（「判定」など）がないか |
| `tests/offline.test.js` | 外部への通信の仕組みや外部の URL がないか。保存先が `localStorage` の1つのキーだけか |

## ローカルでの動作確認

ビルドは不要です。リポジトリのフォルダで簡易サーバーを起動し、ブラウザで開きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

確認するときのポイント：

- 開発者ツールのスマホ表示（幅 375px など）と、端末のダークモードで表示を確かめる
- 2回続けて答えると、2回目の結果に前回の収支（細い金色の棒）が重なる
- 開発者ツールの「Application → Local Storage」で、保存内容を確認できる
- 開発者ツールの「Network」タブで、ページ自身のファイル以外への通信がないことを確認できる

## GitHub Pages での公開

既存のツールと同じく、`main` ブランチのルートを GitHub Pages で公開します。

1. このリポジトリの `main` ブランチに、`index.html` などがある状態にします
2. GitHub のリポジトリ画面で **Settings → Pages** を開きます
3. **Build and deployment** の **Source** で「Deploy from a branch」を選びます
4. **Branch** で `main`、フォルダは `/ (root)` を選んで **Save** を押します
5. 数分待つと、https://tools.coaching-l.net/resource-check/ で公開されます

`tools.coaching-l.net` の独自ドメインは、組織のサイト（`coaching-l/coaching-l.github.io`）に設定されているので、このリポジトリに `CNAME` は要りません。
ツールの一覧ページ（https://tools.coaching-l.net/）に載せるときは、`coaching-l.github.io` の README の「ツールを足すとき」を見てください。

更新するときは、`main` に変更を反映するだけで、自動的に公開内容も更新されます。
`style.css`・`content.js`・`scoring.js`・`app.js` を変えたときは、`index.html` の `?v=1` の数字を1つ上げてください。
GitHub Pages ではファイルがブラウザに10分ほど保存されるため、数字を上げないと、新しい `index.html` と古いファイルが組み合わさって表示が崩れることがあります。

## ファイル構成

```
index.html   画面の骨組み（文言は content.js から差し込みます）
style.css    見た目（スマホ優先・ライト／ダーク対応・印刷用。色はポモドーロタイマーと同じブランドカラー）
content.js   質問・問い・画面の文言のすべて（ここを直せば文言が変わります）
scoring.js   採点（SPEC.md の「2. 採点」）
app.js       画面の動き・保存・収支バー・コピーと印刷
icons/       ロゴ・ファビコン・ホーム画面用アイコン（ポモドーロタイマーと同じ画像）
tests/       テスト（node --test）
SPEC.md      MVP の仕様書
README.md    このファイル
```

### 保存データの形式

```js
// キー：coachingl-resource-check-v1
{
  version: 1,
  current: null | {                 // 進行中の回（回答の途中・ふりかえりの途中）
    id, startedAt, updatedAt,       // 時刻はミリ秒（epoch）
    view: "start" | "questions" | "result" | "reflect" | "step" | "summary",
    page: 0〜4,                     // 質問の何画面目か
    answers: { time: [1〜5 | null, …4つ], focus, emotion, recovery, priority },
    recordId: null | 記録の id,     // 結果を出したあとは、その記録の id
    reflectIndex: 0〜2              // ふりかえりの何問目か
  },
  name: "",                         // お名前（任意。30字まで）。印刷とコピーに入れる
  records: [{                       // 過去の結果（古い順。100件をこえたら古いものから消す）
    id, takenAt, date: "2026-10-20",
    sums: { time: 4〜20, … },       // 領域ごとの合計点（逆転したあと）。得点・収支はここから計算する
    answers: { time: [1〜5, …], … },// 答えそのもの
    reflection: {
      domain: "emotion",            // ふりかえりをした領域
      answers: ["", "", ""],        // 3問の記入（各400字まで）
      choices: [null, "心と体をゆるめる", null]  // 選択肢のある問いで選んだもの
    },
    step: "",                       // 小さな一歩（400字まで）
    updatedAt
  }]
}
// 知らない項目は捨てずに残します（新しい版で足した項目を、古い版で消してしまわないように）
```
